1. Cell segmentation

Cell segmentation is the foundational step for 3D cell atlas construction, which identifies and extracts single-cell regions from spatial-omics images (TIF format). This module supports batch processing of multi-section images and outputs cell coordinate information with high precision.

2. Tissue segmentation

2.1 Environment preparation
# Recommended conda installation (avoid version conflicts)
conda create -n cell_atlas_env python=3.9 -y
conda activate cell_atlas_env
conda install -c conda-forge gdal regex tqdm scikit-image -y
# Or pip installation
pip install gdal regex tqdm glob2 scikit-image
2.2 Test data

Test data is stored in the test_data/spatial_omics/ folder (size ≤ 10MB), including multi-section TIF images (e.g., section_1.tif, section_2.tif) with cell/tissue staining information, which can be used directly without additional download.
